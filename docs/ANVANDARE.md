# Användarappen (gäster/kunder)

Platshållare för den kommande gäst/kund-vända appen — inte påbörjad ännu.
Det här dokumentet fylls i när det arbetet startar. För admin-panelen
(personal & ägare), se [ADMIN.md](ADMIN.md); för API:er och nycklar, se
[API-OCH-NYCKLAR.md](API-OCH-NYCKLAR.md).

## Status

Inte påbörjad. Det här repot (`admin-front-end`) innehåller idag bara
admin-panelen för personal och ägare.

## Tänkt innehåll här (fylls i senare)

- Vad appen är till för (t.ex. gäster som bokar bord, ser meny, hanterar sin
  bokning) och vilket repo/projekt den bor i (eget repo eller egen mapp här —
  bestäms när arbetet startar).
- Projektstruktur, motsvarande avsnitt 2–3 i [ADMIN.md](ADMIN.md).
- Inloggnings-/identifieringsflöde för gäster, om det behövs (troligen inte
  samma Cognito User Pool som personalen — separat pool eller ingen
  inloggning alls beroende på lösning).
- Vilka delar av backend-API:t den använder, med länk till
  [API-OCH-NYCKLAR.md](API-OCH-NYCKLAR.md) för själva nycklarna.
